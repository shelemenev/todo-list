# Todo List

Список задач на React + TypeScript + Vite. Добавление, редактирование, фильтрация, тёмная тема.

## Структура
src/
├── context/ # React-контексты (тема, задачи)
├── components/
│ ├── ThemeToggle/ # Переключатель тёмной/светлой темы
│ ├── TaskForm/ # Поле ввода + кнопка добавления задачи
│ ├── TaskItem/ # Карточка задачи (чекбокс, редактирование, удаление)
│ ├── TaskList/ # Список задач
│ └── FilterButtons/ # Фильтры: Все / Активные / Завершённые


## Стек

- **React 19** + **TypeScript**
- **Vite** — сборка и дев-сервер
- **Vitest** + **Testing Library** — тесты
- **Storybook 10** — разработка и документация компонентов
- **SASS** — стили

## Скрипты

| Команда | Описание |
|---|---|
| `npm run dev` | Дев-сервер (localhost:5173) |
| `npm run build` | Продакшн-билд |
| `npm run preview` | Превью билда |
| `npm test` | Запуск тестов (vitest) |
| `npm run test:watch` | Тесты в watch-режиме |
| `npm run test:coverage` | Тесты с покрытием |
| `npm run lint` | ESLint |
| `npm run storybook` | Storybook (localhost:6006) |
| `npm run build-storybook` | Сборка Storybook |

## Фичи

- Добавление новых задач
- Редактирование названия задачи
- Отметка выполнения чекбоксом (зачёркнутый текст)
- Удаление задач
- Фильтрация: Все / Активные / Завершённые
- Переключение тёмной/светлой темы
